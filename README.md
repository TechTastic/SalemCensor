Welcome to the **Salem Censor** bot Github!

This is simply a quick and dirty bot I made while i was burned out on another project of mine!
What it does is simple!

A message is sent in a server with this bot. That message is then split into multiple words and checked against a series of Tries for swear and banned words. If a banned word is found, such as the N word, it will delete the message outright. If no banned words are found and swear words are found, then it'll replace every swear in the message with an older replacement word that is no longer considered socailly a swear, delete the original message, and send the sanitized message via a WebHook mimicing the original author.

With the new message, there is also a new button that only the original author can use that lists out the filtered swear words.

The original list of swears and their counterparts came from this [Google Spreadsheet](https://docs.google.com/spreadsheets/d/1wH6ifBlHfFnY8dsKtuRv42QZ8rgTi7NiUG4jyIA0qH8/edit?gid=0#gid=0) listing the censored words from the game **Town of Salem**, hence the bot's name!

I will likely update the bot and list over time but for now it does its job adequately enough for me!
